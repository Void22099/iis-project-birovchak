## Структура
- `docs/lab01_pasport.md` — паспорт і 10 запитань.
- `data/raw/support_tickets_synthetic_ua.csv` — 900 *синтетичних* звернень; це навчальний набір, а не реальний архів.
- `knowledge/` — майбутні правила системи.
- `src/` — код наступних робіт.
- `reports/` — звіти.
- `test_clips.py` — контрольний тест CLIPS.

## Запуск у Windows PowerShell
Спочатку встановіть Python 3.11+ та Git. Виконайте команди у папці проєкту:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python test_clips.py
```

При правильному встановленні CLIPS має бути:

```text
CLIPS працює
Спрацювало правил: 1
```

Це **очікуваний результат**; його потрібно підтвердити реальним запуском і власним скріншотом для звіту.

Якщо PowerShell блокує активацію середовища, використовуйте ` .\.venv\Scripts\python.exe -m pip install -r requirements.txt ` і ` .\.venv\Scripts\python.exe test_clips.py `.

Дані згенеровано з авторських шаблонів (10 базових формулювань у кожному з 6 класів, 15 варіантів контексту); випадкові перефразування можуть зберігати сильну схожість.
